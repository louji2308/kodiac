## Mission
The headline ("Same robot, same practice data, only the judge changed: +Y points of success") must be computed **exactly as pre-registered**, with CIs, from real labels, or not at all.
We currently have **no judge labels, no trained arms, and a mock-physics pool**. So: build and *prove correct* the statistics machinery on clearly-synthetic test data, and make the real outputs degrade honestly to `NOT MEASURED`.
A fabricated or placeholder number rendered as if measured is a disqualifying kill-shot (AGENTS Law 1).

## Rules specific to this card
- Never compute a metric differently from `experiments/PREREGISTRATION.md` (read it fully; cite section numbers in docstrings). Truth = oracle `success` at the final step. CAN'T TELL = not accepted; coverage always reported. Thresholds/λ from the **calibration split only**; all judge metrics on the **training split**. Size-matched control = random oracle-successes with |set| = |Kodiac accepted|.
- Tests use `tests/fixtures/proof/` **synthetic** data with a prominent `SYNTHETIC` marker in file names/columns, generated by a seeded script; every function output computed from it must carry/propagate `"synthetic": true` when the input is flagged synthetic.
- Verify stats against known answers: Wilson vs hand-computed reference values (e.g. k=0,n=67; k=33,n=100), exact McNemar vs `scipy.stats.binomtest`, Holm vs a hand example, bootstrap coverage on a known-mean simulation (seeded; assert the CI contains the truth), AUROC vs `sklearn.metrics.roc_auc_score` if sklearn is installed else a rank-based reference.
- `headline()` returns `NOT_MEASURED` unless: ≥4 arms, ≥2 seeds each, ≥200 eval episodes per seed (prereg), and no input flagged mock/synthetic. In all other cases it returns the computed numbers **only with** `"synthetic": true` / `"is_mock": true` and `status="SYNTHETIC_TEST_ONLY"`. The chart renderer refuses to draw bars for anything but `MEASURED` (draws a hatched watermark for `SYNTHETIC_TEST_ONLY`).
- Write `experiments/results/README.md` stating this contract and the *current truth* (no labels/arms exist; results = NOT_MEASURED).
- Do NOT create `experiments/results/headline.json` or any chart under `artifacts/p08/` with synthetic numbers; produce the real-state `NOT_MEASURED` JSON + chart only (via a committed command), written to `experiments/results/headline.json` and `artifacts/p08/proof_chart.{png,svg}` — these are the honest current state.

### 3 ways this could embarrass us, and what I did about each
1. **A chart that looks measured but isn't.** Data marks are drawn only for an unflagged `MEASURED` headline. Unknown or missing flags and unknown statuses fall back to watermarks; pixel and SVG tests cover this. Synthetic numbers never leave pytest tmp. The committed chart is the NOT MEASURED watermark.
2. **Calibration→train leakage.** τ is fitted only on calibration rows (tested by perturbing training scores). Judge metrics use the training split only (tested: n = 200 of 250). Missing labels count against coverage in `n_missing`; they are never dropped.
3. **p-hacking / forking paths.** Every metric's definition is fixed in code before any label exists, with PREREG § citations. Holm keeps degenerate tests in the family. The headline uses the more conservative Welch CI and says "not statistically significant" when Holm p ≥ 0.05. `check_prereg.py` fails if PREREGISTRATION.md or pool_config.yaml change after the tag.
