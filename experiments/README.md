# experiments/

Artifacts, manifests, pre-registration protocols, and analysis scripts for the Kodiac proof suite.

- `PREREGISTRATION.md`: Hypotheses, oracle thresholds, arms, stopping rules, tagged `prereg-v0` / `prereg-v1`.
- `pool_config.yaml`: Episode generation distribution parameters.
- `pool/`: Manifests and references for the practice pool.
- `labels/`: Judge label outputs per baseline and Kodiac variant.
- `results/`: Processed metrics, tables, and visualization artifacts.

## Pool status (honest, as of 2026-11-02)

- `pool/manifest.parquet` holds **250 episodes (200 calibration, 50 train), all `is_mock=True`**: generated by the kinematic mock simulator (`KinematicMockEnv`), with privileged-state `.npz` files only and **no videos**.
- This is **not valid for the headline proof**: ADR-0004 rejects mock episodes from the pool and the target size is 600-1000. It must be regenerated on ManiSkill (via Modal) before any proof use.
- **No model arm has been trained**, so there is no "+Y points" result. `Y` stays a placeholder.
- `artifacts/p04/validation.json` was computed on this pool with tracks synthesised from privileged state (no perception in the loop); it measures engine geometry only.
