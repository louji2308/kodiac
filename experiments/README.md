# experiments/

Artifacts, manifests, pre-registration protocols, and analysis scripts for the Kodiac proof suite.

- `PREREGISTRATION.md`: Hypotheses, oracle thresholds, arms, stopping rules, tagged `prereg-v0` / `prereg-v1`.
- `pool_config.yaml`: Episode generation distribution parameters.
- `pool/`: Manifests and references for the practice pool.
- `labels/`: Judge label outputs per baseline and Kodiac variant.
- `results/`: Processed metrics, tables, and visualization artifacts.
